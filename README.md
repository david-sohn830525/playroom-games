# PLAYROOM

다크 티타늄 스타일로 만든 브라우저 미니게임 컬렉션입니다.

- Snake: 방향키, WASD, 터치 조작
- 2048: 방향키, WASD, 스와이프 조작
- Orbit: 좌우 키와 터치 조작
- 브라우저에 게임별 최고 점수 저장

## 로컬 실행

정적 파일로 구성되어 있습니다. 로컬 서버에서 저장소 루트를 열면 됩니다.

```powershell
python -m http.server 4173
```

## 배포

GitHub 저장소를 Vercel에 연결하고 저장소 루트를 배포합니다. 별도의 빌드 명령이나 출력 폴더 설정은 필요하지 않습니다.
